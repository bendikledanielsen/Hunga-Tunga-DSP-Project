
# Hunga-Tunga DSP Project

## Overview

This repository contains code and exercises related to digital signal processing (DSP).

The project explores signal analysis, mathematical modelling, and data visualization using Python.

## Technologies

- Python 3
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Structure

The repository is organized into different tasks, each containing code and analysis related to a specific DSP topic.

## Getting Started

Clone the repository:

```bash
git clone git@github.com:bendikledanielsen/Hunga-Tunga-DSP-Project.git
```

Navigate to the project directory:

```bash
cd Hunga-Tunga-DSP-Project
```

Install the required Python packages:

```bash
pip install numpy matplotlib jupyter
```

Start Jupyter Notebook:

```bash
jupyter notebook
```
